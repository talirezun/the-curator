# Error messages: what they mean and what to do

When something goes wrong, The Curator says so in plain words. Every message is written to answer three questions:

| | The message tells you | For example |
|---|---|---|
| 1 | **What happened** | "GitHub rejected the token saved for Sync." |
| 2 | **Whether anything was lost or charged**, when that is in question, and only when The Curator knows for sure | "Nothing was lost: your changes are still on this computer." |
| 3 | **The one thing to do next**, naming a button that is on that screen | "Create a new token on GitHub and use Replace token on this page." |

This page lists every message that carries a **code**, grouped by where you meet it.

## The "Technical detail (for support)" line

Under many messages there is a second, smaller line in grey:

```
Anthropic didn't accept the API key saved in The Curator, so the request was refused and not charged. Open Settings › Providers & keys and use Replace key to paste a working key.
Technical detail (for support): 401 {"type":"error","error":{"type":"authentication_error","message":"invalid x-api-key"}} (code: ai-key-rejected)
```

| Part of that line | What it is for |
|---|---|
| The technical text | The original message from the AI provider, GitHub, git or your computer. **You don't need to read it.** If you ask for help, copy the whole line into your message: it tells support exactly what failed. |
| `(code: …)` | A short name for the message. **Search this page for it** (⌘F on a Mac, Ctrl+F on Windows) to find its row. Only codes listed on this page are ever shown as a code. |

**Before it is shown,** The Curator removes access tokens, API keys and passwords it recognises, and shortens folder paths so your home folder's name is not in it. Read it before you paste it anywhere public all the same.

A few more things worth knowing:

- **No code?** The message is one The Curator wrote for that exact situation (for example an ingest refusing with "Nothing was sent to the AI and nothing was charged"). It explains itself, so it is not listed here. Search this page or the [User Guide](user-guide.md#18-troubleshooting) for a few of its words.
- **Words in square brackets**, such as [AI provider] or [file name], are filled in on screen: "Anthropic", "index.md".
- **A sentence before the message.** Sometimes the step that failed adds its own sentence first, then one of the sentences below.
- **Agents see the original text.** An AI agent using The Curator through the MCP gets the technical message, not these sentences: agents read it better than a sentence written for people.

If a message keeps coming back and nothing below helps, use **Run system check** in **Settings › General**, then send the technical detail line to support.

## Sync: replacing the token

Messages in the Replace token panel on the Sync page. In each case Sync keeps the token it had.

| Code | What you see | What it means | What to do |
|---|---|---|---|
| `sync-token-missing` | Paste the new token from GitHub first. Nothing was changed. | Check and save was pressed with the token field empty. | Paste the new token, then press Check and save. |
| `sync-not-configured` | Sync is not connected on this computer, so there is no token to replace. Connect a repository first. | Sync is not connected on this computer, so there is no token to replace. | Connect a repository on the Sync page first. |
| `sync-token-invalid` | That doesn’t look like a GitHub token. Copy the whole token from GitHub (it starts with ghp_ or github_pat_) and paste it again. Nothing was changed. | What was pasted does not look like a GitHub token. Nothing was changed. | Copy the whole token from GitHub again (ghp_… or github_pat_…). |
| `sync-config-unreadable` | The Curator couldn’t read which repository Sync uses, so the token was not changed. Disconnect this repository and connect it again with the new token. | The Curator could not read which repository Sync uses, so it could not check the token. Nothing was changed. | Disconnect this repository and connect it again with the new token. Your wiki files stay as they are. |
| `sync-new-token-rejected` | GitHub didn’t accept the new token. Check that you copied all of it and that it has not expired, then try again. Nothing was changed: Sync still has the token it had. | GitHub refused the new token. Sync keeps the token it had. | Check that you copied all of it and that it has not expired, then try again. |
| `sync-new-token-no-access` | GitHub accepted the token, but it cannot open the repository Sync uses ([repository]). For a fine-grained token, give it that repository with Contents: Read and write; for a classic token, tick the repo scope. Nothing was changed. | The new token is valid but cannot open Sync’s repository. Nothing was changed. | Give the token that repository with Contents: Read and write (fine-grained) or the repo scope (classic). |
| `sync-token-check-offline` | The Curator couldn’t reach GitHub to check the new token, so nothing was changed. Check your internet connection and try again. | The Curator could not reach GitHub to check the new token. Nothing was changed. | Check the internet connection, then try again. |
| `sync-token-check-failed` | The new token couldn’t be checked, so nothing was changed. Try again in a minute; if it keeps happening, copy the technical detail below and send it to support. | The new token could not be checked, for another reason. Nothing was changed. | Try again in a minute. If it repeats, send the Technical detail line to support. |
| `sync-token-save-failed` | The new token works, but The Curator couldn’t save it, so nothing was changed. Try again; if it keeps happening, copy the technical detail below and send it to support. | GitHub accepted the new token, but The Curator could not save it. Sync keeps the token it had. | Try again. If it repeats, send the Technical detail line to support. |

## Where the sentences come from

The sentences in the "What you see" column are not copied by hand. `scripts/build-error-catalogue.mjs` produces them by calling the same code the app uses to write them, and `npm test` fails if this page and the app ever disagree (`scripts/test-error-catalogue.js`). To change a message, change it in the code (`src/public/next/shared/user-errors.js`, or `src/brain/sync.js` for Sync), then run `node scripts/build-error-catalogue.mjs`.

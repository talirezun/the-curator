"The Curator" name and the Curator logo are trademarks of Tali Rezun.

The software licences in this repository — the [MIT License](LICENSE) and the
[Curator Enterprise License](LICENSES/LICENSE-ENTERPRISE.txt) — grant rights in
the **code**. Neither grants any rights in the **name or the logo**. That is
already how the MIT License works; this file simply states it plainly, so that
nobody has to guess.

## Forks and derivative works

You may fork this project freely — both licences allow it.

If you **distribute or host** a fork, please give it a different name and a
different logo. Users should never be unable to tell whether they are running
The Curator or something else, and a fork carrying the original name makes that
impossible.

A private fork you run for yourself is not affected by this at all.

## Permitted nominative use

You do not need permission to refer to The Curator accurately. All of these are
fine:

- "based on The Curator"
- "compatible with The Curator"
- "a fork of The Curator"
- "works with The Curator's Shared Brain"

What is not fine is presenting your product *as* The Curator, or using the logo
in a way that implies endorsement or official status.

## How this is enforced

Calmly, consistently, and in writing. If a use of the name looks like a
problem, the first step is an email explaining why — not a legal threat, and
never a change to how the code is distributed.

Trademark enforcement and code distribution are kept strictly separate here.
Restricting someone's access to the software because of a naming dispute would
be a misuse of both, and this project will not do it.

## Questions

If you are unsure whether a use is acceptable, ask before you ship:
[open an issue](https://github.com/talirezun/the-curator/issues). The answer is
usually yes.

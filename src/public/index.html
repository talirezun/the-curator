Create a private GitHub repository

This is where your knowledge will live. It's private — only you can access it.

1 Go to GitHub and create a new repository Open GitHub ↗
2 Name it anything — e.g. my-brain
3 Make sure Private is selected
4 Leave the repo empty — do NOT tick "Add a README", ".gitignore", or "license". The Curator fills it on the first sync; a pre-filled repo causes the first push to fail.
5 Click "Create repository"
6 Copy the URL from your browser's address bar and paste it below

Create a Personal Access Token

This gives The Curator permission to read and write your private repository on GitHub. We recommend a fine-grained token — it's scoped to just this one repo. (Prefer a classic token that never expires? See the note below.)

1 Open GitHub's fine-grained token page Open Token Page ↗
2 Name it — e.g. the-curator-sync — and pick an Expiration (up to 1 year)
3 Under Repository access, choose Only select repositories → pick the repo you just created
4 Under Permissions → Repository permissions, set Contents to Read and write ← this is the one that matters (Metadata: Read-only is added automatically)
5 Scroll down → click "Generate token"
6 Copy the token shown — it starts with github_pat_
Prefer a token that never expires? Use a classic token instead

Open the classic token page, set Expiration to No expiration, tick the top-level repo scope, then Generate. A classic token starts with ghp_. Either token type works here.

Wiki Health

Click Scan to check this domain's wiki for issues.

Semantic duplicates (AI-powered)

Find pages that describe the same concept under different slugs — like [[rag]] and [[retrieval-augmented-generation]]. This check uses an LLM and has a small cost, so it runs only when you click below.

Fix broken links with AI (AI-powered)

Resolve broken [[wikilinks]] in bulk. Free formatting fixes run first (slugifying, stripping .md); the rest are matched to existing pages by the AI when they're a clear variant, and links pointing at no real page have their brackets removed. You review the full plan before anything is written.

Rescue orphans with AI (AI-powered)

An orphan is a page nothing links to. The AI finds the best existing page to link from for each orphan, in bulk, and you review the plan before it's applied.

Before you use Ask AI

When you click Ask AI, The Curator sends the following to your configured LLM provider (Google Gemini or Anthropic, whichever you set in Settings):

  • A short excerpt (~4 KB) of the wiki page that contains the broken link
  • A list of your wiki's page names (slugs only — not their contents)

The provider's privacy policy applies. To disable this feature, remove your API key in Settings. See docs/ai-health.md for details.
